CockpitAdminSteuerung
lädt … Zelle anklicken und ändern – geänderte Felder werden gelb; „Speichern“ in der Zeile oder oben „Alle speichern“ schreibt in die Datenbank. Index und Achsen rechnet die Maschine. Spaltenbreite: Rand im Kopf ziehen (Doppelklick = Standard).

Was passiert beim Speichern?

Zutaten oder Nährwerte ändern läuft durch die Maschine
  1. Zelle ändern → wird gelb → „Speichern“.
  2. Alte Zutaten-Zuordnung wird im Verlauf gesichert und gelöscht.
  3. Maschine liest die neue Liste: erkennt jede Zutat, E-Nummern, Zusatzstoffe.
  4. Zusatzstoffe werden neu abgeleitet (außer du hast sie selbst eingetragen).
  5. Index, Achsen und NOVA werden neu gerechnet – sofort in der Zeile sichtbar.
  6. War das Produkt „Abgelehnt/Inaktiv“, wird es automatisch „Entwurf“.
  7. Live (Aktiv) geht es erst, wenn der Freigabe-Takt alle Wächter grün sieht.
Stammdaten ändern nur speichern
  1. Name, Marke, EAN, Menge → werden direkt übernommen.
  2. Quelle (z. B. Herstellerseite) → wird am Produkt vermerkt.
  3. Status → wird direkt gesetzt, ohne Neuberechnung.
  4. ★ Ralph → deine persönliche Markierung (Haken). Filter oben: Status → „★ Bei Ralph“. Ändert nichts an Maschine oder Index.
  5. Zusatzstoffe (Status/Stoffe) von Hand → Index wird neu gerechnet, deine Angabe bleibt.
  6. Nährstoffe laut Etikett: eine Zeile je Stoff, z. B. L-Leucin 10,8 g oder Vitamin D3 20 µg (400 %) (Zahl in Klammern = % NRV). Bezug daneben wählen (pro 100 g, pro Portion, Tagesdosis …). Speichern ersetzt die ganze Liste; Index wird neu gerechnet.
Herstellerabgleich (Stand) nur Markierung
  1. verifiziert = Hersteller-Zutaten stimmen mit unseren überein.
  2. korrigiert = du hast unsere Daten an die Herstellerseite angepasst. Die Korrektur selbst machst du in der Zutaten-Spalte – der Stand ist nur das Häkchen.
  3. abweichend / Ralph vorlegen = passt nicht, muss geklärt werden.
  4. nicht lesbar / keine Seite = Seite fehlt oder ist nicht auslesbar.
  5. URL eintragen → ↗ öffnet die Seite. Nichts wird neu gerechnet.
Jede Änderung steht mit alt → neu im Verlauf (wer, wann). Tipp: Zutaten korrigieren + Stand „korrigiert“ + Quelle „Herstellerseite“ in einem Rutsch, dann einmal speichern.
