Cut and paste files on a Mac

Coming from Windows, you press ⌘X in Finder – and nothing happens, because Finder can't cut files.

How to do it in Finder

Finder can move files, it just works differently from Windows. There are two ways:

  1. Copy, then paste as move: select the file and press ⌘C. In the destination folder press ⌥⌘V. In the Edit menu it's called “Move Item Here” and only appears while you hold the Option key (⌥). The file disappears from its old location.
  2. Drag: dragging a file to another folder on the same drive moves it. Dragging to a different drive (USB stick, NAS) copies it – hold ⌘ while dragging to move it there too.

This works reliably. You just have to remember that the “move” decision happens when you paste, not when you cut.

How to do it with Foldair

In Foldair it works the way you know from Windows:

  1. Select a file or folder and press ⌘X (or Edit › Cut).
  2. Go to the destination folder and press ⌘V. The file is moved.

There's also “Move to …” in the Edit menu, and a progress bar with time remaining for large files. Foldair asks before it overwrites anything.

Frequently asked questions

Does ⌘X delete the file right away?

No. The file stays where it is until you paste with ⌘V. If you copy something else in the meantime, it simply stays in its old place.

Why can't Finder cut files with ⌘X?

Apple handles moving differently: you copy with ⌘C and decide to move when you paste with ⌥⌘V.
